# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub (the repository's **Security** tab > **Report a vulnerability**) or by email to security@ketapay.com. We reply within two working days and keep you updated until it's fixed.

Include what you found, how to reproduce it, and which example it affects. If it affects the KetaPay API or an SDK rather than these examples, report it the same way and we'll route it.

## Handling secrets

Never paste secret keys (`sk_live_`, `sk_test_`), customer tokens or webhook secrets into issues, pull requests or logs. If you've exposed a key, roll it in the KetaPay dashboard straight away.
